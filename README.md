# Reckon Automation Templates (n8n, Make.com, Zapier & Clay)

Ready-to-import agency automation templates powered by the **4-Actor Reckon Apify Suite**.

## Live Apify Actors
1. **[Reckon All-in-One Suite](https://apify.com/krazyarcher/reckon-all-in-one-suite)** — Complete funnel in 1 call: Lead Qualification -> White-Label HTML/PDF Audit -> `llms.txt` + JSON-LD GEO Fix Kit.
2. **[ReckonSEO Auditor](https://apify.com/krazyarcher/reckonseo-auditor)** — Fast ~2-5s technical SEO, SSL, mobile/form leak & AI-Search auditor with clickable HTML/PDF report URLs.
3. **[ReckonGEO Generator](https://apify.com/krazyarcher/reckongeo-generator)** — Auto-generates `llms.txt`, `LocalBusiness`/`FAQPage` JSON-LD schema & AI-crawler `robots.txt` patches.
4. **[ReckonLeads Filter](https://apify.com/krazyarcher/maps-broken-leads)** — Filters Google Maps Scraper output for No-Website, Social-Only, Expired-SSL & Broken-Site leads.
